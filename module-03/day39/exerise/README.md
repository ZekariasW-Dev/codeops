## Menu and orders

- `GET /api/dishes` returns the menu, and `GET /api/dishes/[id]` returns one dish.
- `POST /api/orders` accepts `name`, `phone`, `area`, and optional `notes`. Invalid fields are returned as `fieldErrors`.
- Checkout uses a server action. Orders can be cancelled from the same session that created them.

Orders are kept in memory for this exercise, so they are cleared when the server restarts.

# Ethiopian Food Menu

A simple React project that displays an Ethiopian restaurant menu using React components, props, and array mapping.

## Features

* React components
* Props with destructuring
* Header component
* Dish components
* Rendering dishes with `map()`
* Unique keys for each dish

## How to Run

Clone the project:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go into the project:

```bash
cd dish-menu
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

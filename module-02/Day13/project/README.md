# Bole Cafe - Business Profile Card

## Business Name
**Bole Cafe** - A cozy coffee shop in Bole, Addis Ababa

## How to Open
1. Open `index.html` in your browser
2. The CSS is linked externally via `styles.css`

## CSS Techniques Used
- ✅ CSS Variables (custom properties) on `:root`
- ✅ `box-sizing: border-box` global reset
- ✅ Web font from Google Fonts (Inter)
- ✅ Box model: padding, border, border-radius, margin
- ✅ Typographic hierarchy (h1, tagline, body text)
- ✅ Button with `:hover` state using HSL lightness change
- ✅ `:focus` outline for accessibility
- ✅ `::before` pseudo-element for decorative accent
- ✅ No inline styles
- ✅ No ID used for styling

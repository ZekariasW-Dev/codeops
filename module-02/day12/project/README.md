# Habesha Eatery Mini-Site

Habesha Eatery is a fictional Ethiopian restaurant located in Bole, Addis Ababa.

## Pages

- `index.html` — Reservation page with a reservation form, Ethiopian menu table, image, and map.
- `contact.html` — Contact form and opening-hours table.

## How to Open the Site

Download or clone the repository and open `index.html` in a web browser.

The Contact page can be accessed through the navigation link at the top of the reservation page.

## Accessibility Features

The site includes:

- Semantic HTML elements such as `header`, `nav`, `main`, `section`, and `footer`.
- One `h1` heading on each page.
- Unique page titles and meta descriptions.
- Labels connected to every form control.
- Appropriate input types such as `email`, `date`, `time`, and `number`.
- Required form fields.
- Keyboard-accessible links and buttons.
- Tables with captions.
- Table headers using `scope="col"`.
- Meaningful alternative text for images.
- A descriptive title for the map iframe.
- Logical heading structure.
- Navigation links shared between both pages.

## Validation

Both pages should be tested using the W3C HTML Validator and corrected until there are zero errors.

# Reflection

## 1. What is the difference between Git and GitHub?

Git is a version control system used to track changes in source code locally. GitHub is a cloud-based platform that hosts Git repositories and enables collaboration among developers.

## 2. What is the purpose of the terminal?

The terminal allows users to interact with the operating system using commands to manage files, run programs, automate tasks, and use developer tools such as Git.

## 3. What does git add do?

The git add command stages new or modified files, preparing them to be included in the next commit.

## 4. What is the purpose of git commit?

The git commit command saves the staged changes into the repository history with a descriptive message.

## 5. Write the daily Git workflow in the correct order.

1. git pull
2. Make changes
3. git status
4. git add .
5. git commit -m "Commit message"
6. git push
